# Shop image uploads

Upload final product photography here. Use one folder per product:

- `mushroomiya/`
- `fold/`
- `fungal-art-series/`
- `mycelium-hotline/`
- `masterclass/`

Use web-ready JPG, PNG, or WebP files. Name the primary card image `hero.*` and additional gallery images `detail-01.*`, `detail-02.*`, and so on. Avoid spaces in filenames.

When images are uploaded, the shop catalogue can be updated to use them directly.
